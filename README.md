# SOL Results — University Examination & Marks ERP Portal

Production-grade Examination & Grading ERP System built with React, Vite, Tailwind CSS, Lucide React, Recharts, and Express.js / MySQL.

## Features
- **Teacher Marks Portal**: Excel Upload, Manual Grid Entry, Validation Engine, Rejection & Correction Resubmission Flow, Audit History Log, PDF Report Generation.
- **Admin Branch**: Multi-role review & approval pipeline.
- **Student View**: Published Statement of Marks & Grade Cards.
